Download **polyomino-search-windows-x64.zip**, extract it, and open the extracted folder.

Type `cmd` in File Explorer's address bar and press Enter. Then run:

```bat
polyomino-search.exe --threads 4 --seconds 300
```

Alternatively double-click **Open Command Prompt.cmd**.

Standalone Windows x64 executable with the C++ runtime linked statically. No compiler or separate C++ runtime installation is required. Includes instructions and ten validated example witnesses.

Supports all 79 requested classes, single targets, multithreading, witness quotas, and exact bounded proofs. Randomized failures remain UNKNOWN; absence proofs apply only within the reported bounds.
